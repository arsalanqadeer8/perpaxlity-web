## 2025-07-31 - [Password Toggle Accessibility & ARIA States]
**Learning:** Password visibility toggle buttons (such as those dynamically switching text between "Show" and "Hide") are highly interactive elements but remain functionally ambiguous or completely inaccessible to screen readers and other assistive technologies. Simply changing the button's text content (using `textContent`) does not announce a state change correctly. Incorporating explicit semantic attributes like `aria-label`, state markers (`aria-pressed`), and explicit DOM relationships (`aria-controls`) ensures screen reader users are notified when hidden inputs are toggled to cleartext.
**Action:** Always pair visible text password toggles with dynamic `aria-label` and `aria-pressed` updates inside the click/interaction handler, and explicitly link the control button to the target input with the `aria-controls` attribute.
